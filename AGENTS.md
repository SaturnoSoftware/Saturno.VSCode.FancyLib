# Saturno.VSCodeKit - agent guide

Thin pointer, per `_SATURNO_BRAIN/CONTEXT/SATURNO/STANDARDS/documentation/AI-TOOL-CONFIG.md`.
Nothing here restates a rule that lives somewhere canonical.

## First rule (non-negotiable)

Never commit, co-author, sign, or label repository changes as AI, Copilot, Claude, Codex,
or any other assistant. No AI trailers, no AI signatures, no "generated by AI" traces.
Preserve the human authorship the repository already declares.

## Plain ASCII punctuation (non-negotiable)

No em dash, en dash, curly quotes, ellipsis character, arrows, emoji or box-drawing, in code,
comments, docs, commit messages or generated files. Accented letters stay - they are
orthography, not decoration. Full standard:
`_SATURNO_BRAIN/CONTEXT/SATURNO/STANDARDS/PLAIN-TEXT-CHARSET.md`.

## Code style - the three layers

This repository carries no style guide of its own. The stack is declared in
`_SATURNO/VERSION.json` and the rules live in `_SATURNO_BRAIN/CONTEXT/SATURNO/STANDARDS/code-standards/`:

1. **`SATURNO-STYLEGUIDE.md`** - the naming model, the file header, the charset rule. Applies
   to every language.
2. **`languages/TYPESCRIPT.md`** - what the language forces.
3. **`platforms/`** - the VS Code extension guide, for what the runtime forces.

The naming model in one line, because it is what gets missed most: public `PascalCase`,
private `_PascalCase`, static `sPascalCase`, constant `UPPER_SNAKE_CASE`, parameter
`camelCase`, local variable `snake_case`. It **disagrees** with the default `eslint` config,
and that is expected.

## What this repo is

The library shared by the three Fancy extensions, consumed as a **git submodule** at
`libs/Saturno.VSCodeKit`, not as an npm package. Before changing anything, read
`_SATURNO/docs/ARCHITECTURE.md` - especially the cut between what depends on `vscode` and
what does not, which is what keeps the core testable.

**A change here reaches three repositories.** A changed signature that is not checked against
the consumers breaks all three at once, and today only `vscode-fancy-header` compiles this lib
in its own test run.
